15.2.2 MALÁRIA

Nesse estudo, quarenta e quatro camundongos foram aleatoriamente divididos em três grupos e todos foram infectados pela malária (Plasmodium berguei).

15.2.3 CÂNCER DE PULMÃO

Um estudo clínico observacional conduzido pelo North Central Cancer Treatment Group (NCCTG), nos Estados Unidos, acompanhou 228 pacientes diagnosticados com câncer de pulmão em estágio avançado, com o objetivo de investigar fatores associados à sobrevivência desses pacientes.

A resposta de interesse foi o tempo de sobrevivência dos pacientes, medido em dias, considerando a ocorrência do óbito como evento de interesse. Os pacientes que não apresentaram o evento durante o período de acompanhamento foram considerados censurados à direita.

Neste estudo, investigaremos a associação entre o tempo de sobrevivência e duas características dos pacientes: sexo (masculino ou feminino) e idade (em anos). Além dos efeitos individuais dessas covariáveis, será avaliada a possível interação entre sexo e idade, buscando verificar se a associação entre idade e sobrevivência difere entre homens e mulheres.

A base de dados, denominada lung, está disponível no pacote survival do software R.

15.2.4 AIDS

O estudo é constituído de pacientes portadores de HIV atendidos entre 1986 e 2000 no Instituto de Pesquisa Clínica Evandro Chagas (Ipec/Fiocruz). Dessa coorte, obteve-se uma amostra de 156 indivíduos que foram diagnosticados como portadores de AIDS (critério CDC 1993) durante o período de acompanhamento. O objetivo é mensurar o tempo, em dias, do diagnóstico até a morte dos pacientes. Para comparação da sobrevivência, vamos ver como o tipo de tratamento impacta a sobrevivência: terapia antirretroviral: A = nenhum, B = mono, C = combinada, D = potente. 15.4 UMA COVARIÁVEL

Para entendermos bem a saída dos modelos de regressão paramétricos e a interpretação dos coeficientes, esta seção é dedicada ao estudo desses modelos considerando somente uma covariável.

15.4.1 UMA COVARIÁVEL QUANTITATIVA

Vamos ilustrar esse cenário com a base de dados de leucemia aguda. Para isso, vamos carregar a base de dados:

Código 
temp<-c(65,156,100,134,16,108,121,4,39,143,56,26,22,1,1,5,65)
cens<-c(rep(1,16),0)
log10_wbc<-c(3.36,2.88,3.63,3.41,3.78,4.02,4.00,4.23,3.73,3.85,3.97,
         4.51,4.54,5.00,5.00,4.72,5.00)
dados1<-data.frame(temp,cens,log10_wbc)

Para esta base de dados, consideraremos a seguinte estrutura regressora: \[\beta_0+\beta_1x_i,\] em que \(x_i\) é o valor de log10_wbc para o \(i\)-ésimo paciente, com \(i=1,...,17\).

15.4.1.1 AJUSTE DE MODELOS PARAMÉTRICOS

Para ajustar cada um dos 5 modelos de regressão paramétricos vistos na disciplina, considere os seguintes comandos:

Código 
ajuste_exp<-flexsurvreg(data=dados1,                                                    Surv(temp,cens)~log10_wbc,
                        dist="exponential")
ajuste_wei<-flexsurvreg(data=dados1,                                                    Surv(temp,cens)~log10_wbc,
                        dist="weibull")
ajuste_lognorm<-flexsurvreg(data=dados1,                                                    Surv(temp,cens)~log10_wbc,
                        dist="lognormal")
ajuste_gama<-flexsurvreg(data=dados1,                                                    Surv(temp,cens)~log10_wbc,
                        dist="gamma")
ajuste_gengama<-flexsurvreg(data=dados1,                                                    Surv(temp,cens)~log10_wbc,
                        dist="gengamma")

MODELO EXPONENCIAL

Para o modelo exponencial, tem-se a seguinte saída:

Código 
tidy(ajuste_exp)
# A tibble: 2 × 5
  term      estimate std.error statistic p.value
  <chr>        <dbl>     <dbl>     <dbl>   <dbl>
1 rate      0.000384  0.000675     NA    NA     
2 log10_wbc 0.943     0.430         2.19  0.0284

De acordo com o modelo ajustado, temos que:

  • rate = \(exp\{\hat{\beta_0}\}=0,0004\rightarrow \hat{\beta_0} = ln(0,0004) = -7.82\)
  • \(\hat{\beta_1}=0.943\)

Portanto, cada tempo de sobrevivência \(T_i\) possui a seguinte distribuição:

\[T_i\sim Exp(\hat{\alpha_i}=e^{-7.82 + 0.943x_i})\]

Com essa distribuição estimada, podemos obter todas as quantidades de interesse em sobrevivência (funções básicas e medidas-resumo), para cada indivíduo.

Nesse modelo:

  • A estimativa de \(\hat{\beta_0}\) é negativa
  • A estimativa de \(\hat{\beta_1}\) é positiva

Podemos interpretar o coeficiente \(\hat{\beta_1}\) da seguinte forma, a partir da RTM:

Código 
Est = exp(-ajuste_exp$coefficient)
IC = exp(-confint(ajuste_exp))

15.4.2 UMA VARIÁVEL QUALITATIVA

Para uma única variável qualitativa, vamos considerar a base de dados de malária com a variável explicativa grupos. Para isso, vamos carregar a base de dados:

Código 
temp<-c(7,8,8,8,8,12,12,17,18,22,30,30,30,30,30,30,8,8,9,10,10,14,
          15,15,18,19,21,22,22,23,25,8,8,8,8,8,8,9,10,10,10,11,17,19)

grupos<-c(rep("Grupo 1",16), rep("Grupo 2",15), rep("Grupo 3",13))
dados2<-data.frame(temp,cens,grupos)

Para esta base de dados, o Grupo 1 será a referência e consideraremos a seguinte estrutura regressora: \[\beta_0+\beta_1x_{i1}+\beta_2x_{i2},\] em que:

  • \(x_{i1}\) é uma indicadora do rato estar no Grupo 2
  • \(x_{i2}\) é uma indicadora do rato estar no Grupo 3

Como a variável é qualitativa, é bem interessante começar a análise fazendo um teste de comparação de curvas de sobrevivência, que já aprendemos. Esse passo é feito para verificar se a variável tem potencial para participar do modelo final. Seguem os comandos que aplicam os testes LogRank e Peto-Peto:

  • O parâmetro de forma estimado foi extremamente negativo, com \(\hat{Q} = -18.4\). Embora valores negativos para \(Q\) sejam permitidos na parametrização adotada pelo pacote flexsurv, magnitudes muito elevadas podem indicar instabilidade numérica ou dificuldades de identificabilidade do modelo.

    • Nesses casos, os coeficientes das covariáveis tornam-se instáveis e sensíveis a pequenas variações nos dados

  • Os erros-padrão associados aos parâmetros foram excessivamente pequenos para um tamanho amostral reduzido, sugerindo uma superfície de verossimilhança artificialmente muito concentrada.

  • O modelo gama generalizado possui maior flexibilidade e maior número de parâmetros em relação aos modelos exponencial, Weibull, gama e log-normal, aumentando o risco de sobreajuste em amostras pequenas.

  • A melhora substancial observada no AIC e no BIC pode refletir não apenas melhor capacidade de ajuste, mas também adaptação excessiva às particularidades da amostra analisada.

Dessa forma, será feita a análise final com o modelo de regressão Lognormal.

15.5.1 SELEÇÃO DAS COVARIÁVEIS: GAMA GENERALIZADA

Como ponto de partida, vamos considerar a distribuição gama generalizada, que possui os parâmetros \(\mu\), \(\sigma\) e \(Q\). Na parametrização do pacote flexsurv, as covariáveis entram, por padrão, no parâmetro \(\mu\):

\[ T_i\sim GG(\mu_i,\sigma,Q). \]

Para permitir a interpretação da estrutura regressora, definiremos:

  • \(a_i\): idade do \(i\)-ésimo paciente, em anos;
  • \(s_i=0\): paciente do sexo masculino (referência);
  • \(s_i=1\): paciente do sexo feminino.

Vamos comparar cinco especificações:

Modelo Estrutura regressora para \(\mu_i\)
M0 — sem covariáveis \(\beta_0\)
M1 — sexo \(\beta_0+\beta_1s_i\)
M2 — idade \(\beta_0+\beta_2a_i\)
M3 — sexo + idade \(\beta_0+\beta_1s_i+\beta_2a_i\)
M4 — sexo + idade + interação \(\beta_0+\beta_1s_i+\beta_2a_i+\beta_3s_ia_i\)

15.5.1.2 COMO INTERPRETAR O MODELO COM INTERAÇÃO?

No modelo M4, a estrutura regressora é dada por:

\[ \mu_i=\beta_0+\beta_1s_i+\beta_2a_i+\beta_3s_ia_i. \]

A expressão sexo * age inclui os efeitos principais (sexo e age) e o termo de interação (sexo:age). Como os homens são a categoria de referência, temos:

Homens (\(s_i=0\)):

\[ \mu_i=\beta_0+\beta_2a_i. \]

Mulheres (\(s_i=1\)):

\[ \mu_i=(\beta_0+\beta_1)+(\beta_2+\beta_3)a_i. \]

Assim, o efeito da idade é representado por \(\beta_2\) entre os homens e por \(\beta_2+\beta_3\) entre as mulheres. As razões de tempos associadas ao aumento de um ano de idade são:

\[ RT_{\text{idade, homens}}=e^{\beta_2},\qquad RT_{\text{idade, mulheres}}=e^{\beta_2+\beta_3}. \]

Além disso, o efeito do sexo passa a depender da idade. Para pacientes com a mesma idade \(a\), a razão entre os tempos característicos das mulheres e dos homens é:

\[ RT_{\text{mulheres/homens}}(a)=e^{\beta_1+\beta_3a}. \]

Portanto, \(\beta_3\) indica se a associação entre idade e tempo de sobrevivência difere entre homens e mulheres. A hipótese de ausência de interação é:

\[ H_0:\beta_3=0\qquad\text{versus}\qquad H_1:\beta_3\neq0. \]

Atenção: na presença de interação, o coeficiente isolado de sexoFeminino representa a comparação entre os sexos quando a idade é igual a zero, uma condição sem interesse clínico nesta base. Para uma interpretação mais útil, poderíamos centralizar a idade em 60 anos; entretanto, manteremos age na escala original para reproduzir os ajustes anteriores.

Observe que o TRV entre Weibull e gama generalizada apresentou p = 0.94. Assim, não há evidências de que o parâmetro adicional da gama generalizada melhore o ajuste em relação à Weibull.

Como a Weibull também apresentou os menores AIC e BIC, ela será a distribuição escolhida. A proximidade entre gama e Weibull nos critérios de informação indica que a primeira também seria uma alternativa plausível.

Importante: um TRV não significativo não demonstra que os modelos sejam idênticos nem que a distribuição selecionada seja perfeita. Por isso, ainda faremos a análise de resíduos.

15.5.4.1 RESÍDUOS DE COX-SNELL

O resíduo de Cox-Snell corresponde ao risco acumulado estimado no tempo observado para cada paciente:

\[ R_i^{CS}=\widehat H(t_i\mid \mathbf{x}_i). \]

Se o modelo estiver bem especificado, esses resíduos devem se comportar como observações de uma exponencial padrão, considerando a censura dos tempos originais.

Os gráficos diagnósticos são construídos com os seguintes comandos:

Código

  Surv(ResiduoCS, dados$evento) ~ 1,

A adequação é sugerida quando a curva de risco acumulado acompanha aproximadamente a reta \(H(r)=r\) e a curva de sobrevivência se aproxima da função \(S(r)=e^{-r}\). Desvios sistemáticos, especialmente nas extremidades, podem indicar falta de ajuste, embora a variabilidade seja maior nessas regiões.

15.5.4.2 RESÍDUOS QUANTÍLICOS ALEATORIZADOS

Também utilizaremos os resíduos quantílicos aleatorizados, definidos por:

\[ R_i^Q=\Phi^{-1}(U_i), \]

em que \(\Phi^{-1}\) é a função quantílica da normal padrão e:

\[ U_i=\begin{cases} \widehat F(t_i\mid\mathbf{x}_i), & \text{se ocorreu óbito},\\ \operatorname{Uniforme}(\widehat F(t_i\mid\mathbf{x}_i),1), & \text{se censurado}. \end{cases} \]

Se o modelo estiver adequadamente especificado e a censura for não informativa, esperamos que os resíduos quantílicos aleatorizados se comportem aproximadamente como uma amostra normal padrão.

Seguem os comandos que calculam os resíduos:

Código 
set.seed(123) # Reprodutibilidade da aleatorização

survival <- NULL
quantilic <- NULL
cdf <- NULL
Residuo <- NULL

for (i in 1:nrow(dados)) {

  survival[i] <- summary(
    ajuste_wei,
    type = "survival",
    newdata = dados[i, , drop = FALSE],
    t = dados$time[i],
    ci = FALSE
  )[[1]]$est

  cdf[i] <- 1 - survival[i]

  # evento = 1 indica óbito; evento = 0 indica censura
  if (dados$evento[i] == 1) {
    quantilic[i] <- cdf[i]
  } else {
    quantilic[i] <- runif(1, min = cdf[i], max = 1)
  }

  # Evitar infinitos devido a arredondamento numérico
  quantilic[i] <- pmin(
    pmax(quantilic[i], .Machine$double.eps),
    1 - .Machine$double.eps
  )

  Residuo[i] <- qnorm(quantilic[i])
}

Embora valores negativos para $Q$ sejam permitidos na parametrização adotada pelo pacote [flexsurv](https://chjackson.github.io/flexsurv/?utm_source=chatgpt.com), magnitudes muito elevadas podem indicar instabilidade numérica ou dificuldades de identificabilidade do modelo.
   * Nesses casos, os coeficientes das covariáveis tornam-se instáveis e sensíveis a pequenas variações nos dados

- Os erros-padrão associados aos parâmetros foram excessivamente pequenos para um tamanho amostral reduzido, sugerindo uma superfície de verossimilhança artificialmente muito concentrada.

- O modelo gama generalizado possui maior flexibilidade e maior número de parâmetros em relação aos modelos exponencial, Weibull, gama e log-normal, aumentando o risco de sobreajuste em amostras pequenas.

- A melhora substancial observada no AIC e no BIC pode refletir não apenas melhor capacidade de ajuste, mas também adaptação excessiva às particularidades da amostra analisada.

Dessa forma, será feita a análise final com o modelo de regressão Lognormal.

### **SELEÇÃO DAS COVARIÁVEIS: GAMA GENERALIZADA**

Como ponto de partida, vamos considerar a **distribuição gama generalizada**, que possui os parâmetros $\mu$, $\sigma$ e $Q$. Na parametrização do pacote `flexsurv`, as covariáveis entram, por padrão, no parâmetro $\mu$:

$$
T_i\sim GG(\mu_i,\sigma,Q).
$$

Para permitir a interpretação da estrutura regressora, definiremos:

- $a_i$: idade do $i$-ésimo paciente, em anos;
- $s_i=0$: paciente do sexo masculino (**referência**);
- $s_i=1$: paciente do sexo feminino.

Vamos comparar cinco especificações:

| Modelo | Estrutura regressora para $\mu_i$ |
|:--|:--|
| **M0** — sem covariáveis | $\beta_0$ |
| **M1** — sexo | $\beta_0+\beta_1s_i$ |
| **M2** — idade | $\beta_0+\beta_2a_i$ |
| **M3** — sexo + idade | $\beta_0+\beta_1s_i+\beta_2a_i$ |
| **M4** — sexo + idade + interação | $\beta_0+\beta_1s_i+\beta_2a_i+\beta_3s_ia_i$ |

#### **AJUSTE DOS MODELOS GAMA GENERALIZADA**

Para ajustar os cinco modelos, considere os seguintes comandos:

```{r}
# Sem covariáveis

  data = dados, dist = "gengamma"
)

  Surv(time, evento) ~ sexo + age,
  data = dados, dist = "gengamma"
```


#### **COMO INTERPRETAR O MODELO COM INTERAÇÃO?**

No modelo M4, a estrutura regressora é dada por:

$$
\mu_i=\beta_0+\beta_1s_i+\beta_2a_i+\beta_3s_ia_i.
$$

A expressão `sexo * age` inclui os **efeitos principais** (`sexo` e `age`) e o **termo de interação** (`sexo:age`). Como os homens são a categoria de referência, temos:

**Homens ($s_i=0$):**

$$
\mu_i=\beta_0+\beta_2a_i.
$$

**Mulheres ($s_i=1$):**

$$
\mu_i=(\beta_0+\beta_1)+(\beta_2+\beta_3)a_i.
$$

Assim, **o efeito da idade** é representado por $\beta_2$ entre os homens e por $\beta_2+\beta_3$ entre as mulheres. As razões de tempos associadas ao aumento de um ano de idade são:

$$
RT_{\text{idade, homens}}=e^{\beta_2},\qquad
RT_{\text{idade, mulheres}}=e^{\beta_2+\beta_3}.
$$

Além disso, **o efeito do sexo passa a depender da idade**. Para pacientes com a mesma idade $a$, a razão entre os tempos característicos das mulheres e dos homens é:

$$
RT_{\text{mulheres/homens}}(a)=e^{\beta_1+\beta_3a}.
$$

Portanto, **$\beta_3$ indica se a associação entre idade e tempo de sobrevivência difere entre homens e mulheres**. A hipótese de ausência de interação é:

$$
H_0:\beta_3=0\qquad\text{versus}\qquad H_1:\beta_3\neq0.
$$

> **Atenção:** na presença de interação, o coeficiente isolado de `sexoFeminino` representa a comparação entre os sexos **quando a idade é igual a zero**, uma condição sem interesse clínico nesta base. Para uma interpretação mais útil, poderíamos centralizar a idade em 60 anos; entretanto, manteremos `age` na escala original para reproduzir os ajustes anteriores.

### **INTERPRETAÇÃO DO MODELO WEIBULL**

**MODELO WEIBULL**

Para o modelo selecionado, temos a seguinte saída:

```{r}
tidy(ajuste_wei)
```

Na parametrização **AFT da distribuição Weibull**, temos:

$$
T_i\sim Weibull(\kappa_i,\gamma),
\qquad \kappa_i=e^{\beta_0+\beta_1s_i},
$$

em que $\kappa_i$ é o parâmetro de escala, $\gamma>0$ é o parâmetro de forma e $s_i=1$ indica o sexo feminino ($s_i=0$ para o masculino).

De acordo com o modelo ajustado, podemos obter as estimativas dos parâmetros:

```{r}
# Parâmetros da Weibull (escala basal e forma)
ajuste_wei$res

# Estimativas dos coeficientes na escala linear
coef(ajuste_wei)
```

Logo, a escala estimada pode ser escrita como:

$$
\widehat{\kappa}_i
=\exp\big(`r round(log(ajuste_wei$res["scale", "est"]), 3)`
+(`r round(coef(ajuste_wei)["sexoFeminino"], 3)`)s_i\big),
\qquad
\widehat{\gamma}=`r round(ajuste_wei$res["shape", "est"], 3)`.
$$

Para interpretar o coeficiente do sexo, utilizaremos a **razão de tempos (RT)**. No modelo Weibull AFT, a razão de tempos entre mulheres e homens é:

$$
RT_{\text{Feminino/Masculino}}=e^{\beta_1}.
$$

Podemos estimar a razão de tempos e seu intervalo de confiança de 95%:

```{r}
# Estimativa e IC95% da razão de tempos
Est <- exp(coef(ajuste_wei)["sexoFeminino"])
IC <- exp(confint(ajuste_wei)["sexoFeminino", ])

Est
IC
```

Assim, a **razão de tempos estimada (mulheres em relação aos homens)** é de **`r round(as.numeric(Est), 2)`**, com **IC95% [`r round(IC[1], 2)`; `r round(IC[2], 2)`]**.

`r if (Est > 1) paste0("O tempo mediano estimado das mulheres é ", round(100*(Est-1),1), "% maior do que o dos homens.") else paste0("O tempo mediano estimado das mulheres é ", round(100*(1-Est),1), "% menor do que o dos homens.")` Essa interpretação também vale para **outros quantis da distribuição dos tempos** sob o modelo AFT.

`r if (IC[1] <= 1 && IC[2] >= 1) "Como o intervalo de confiança contém 1, a diferença não é estatisticamente significativa ao nível de 5%." else "Como o intervalo de confiança não contém 1, há evidências de diferença estatisticamente significativa ao nível de 5%."`

> **Interpretação importante:** a razão de tempos (RT) **não é uma razão de riscos (HR)**. A primeira compara a escala temporal, enquanto a segunda compara as funções de risco.

### **ANÁLISE DE RESÍDUOS**

Após a seleção do modelo, vamos investigar a **adequação do ajuste Weibull** por meio dos resíduos de **Cox-Snell** e dos **resíduos quantílicos aleatorizados**.

#### **RESÍDUOS DE COX-SNELL**

O resíduo de Cox-Snell corresponde ao **risco acumulado estimado** no tempo observado para cada paciente:

$$
R_i^{CS}=\widehat H(t_i\mid \mathbf{x}_i).
$$

Se o modelo estiver bem especificado, esses resíduos devem se comportar como observações de uma **exponencial padrão**, considerando a censura dos tempos originais.

Os gráficos diagnósticos são construídos com os seguintes comandos:

```{r}
ResiduoCS <- coxsnell_flexsurvreg(ajuste_wei)$est

par(mfrow = c(1, 2))

ekm <- survfit(
  Surv(ResiduoCS, dados$evento) ~ 1,
  type = "kaplan-meier"
)

# Risco acumulado: comportamento teórico H(r) = r
plot(ekm, fun = "cumhaz",
     xlab = "Resíduos de Cox-Snell",
     ylab = "Função de risco acumulado")
abline(0, 1, col = "red", lwd = 2)

# Sobrevivência: comportamento teórico S(r) = exp(-r)
plot(ekm,
     xlab = "Resíduos de Cox-Snell",
     ylab = "Função de sobrevivência")
```

A adequação é sugerida quando a curva de risco acumulado acompanha aproximadamente a **reta $H(r)=r$** e a curva de sobrevivência se aproxima da **função $S(r)=e^{-r}$**. Desvios sistemáticos, especialmente nas extremidades, podem indicar falta de ajuste, embora a variabilidade seja maior nessas regiões.

#### **RESÍDUOS QUANTÍLICOS ALEATORIZADOS**

Também utilizaremos os **resíduos quantílicos aleatorizados**, definidos por:

$$
R_i^Q=\Phi^{-1}(U_i),
$$

em que $\Phi^{-1}$ é a função quantílica da normal padrão e:

$$
U_i=\begin{cases}
\widehat F(t_i\mid\mathbf{x}_i), & \text{se ocorreu óbito},\\
\operatorname{Uniforme}(\widehat F(t_i\mid\mathbf{x}_i),1), & \text{se censurado}.
\end{cases}
$$

Se o modelo estiver adequadamente especificado e a censura for não informativa, esperamos que os resíduos quantílicos aleatorizados se comportem **aproximadamente como uma amostra normal padrão**.

Seguem os comandos que calculam os resíduos:

```{r}
set.seed(123) # Reprodutibilidade da aleatorização

survival <- NULL
quantilic <- NULL
cdf <- NULL
Residuo <- NULL

for (i in 1:nrow(dados)) {

  survival[i] <- summary(
    ajuste_wei,
    type = "survival",
    newdata = dados[i, , drop = FALSE],
    t = dados$time[i],
    ci = FALSE
  )[[1]]$est

  cdf[i] <- 1 - survival[i]

  # evento = 1 indica óbito; evento = 0 indica censura
  if (dados$evento[i] == 1) {
    quantilic[i] <- cdf[i]
  } else {
    quantilic[i] <- runif(1, min = cdf[i], max = 1)
  }

  # Evitar infinitos devido a arredondamento numérico
  quantilic[i] <- pmin(
    pmax(quantilic[i], .Machine$double.eps),
    1 - .Machine$double.eps
  )

  Residuo[i] <- qnorm(quantilic[i])
}
```

Para construir o **gráfico Q-Q dos resíduos quantílicos**, considere:

A proximidade dos pontos em relação à linha de referência e a ausência de desvios sistemáticos constituem **evidências gráficas favoráveis à adequação do modelo**. A faixa de confiança auxilia na avaliação, mas não é necessário que todos os pontos estejam dentro dela.

Como os resíduos dos pacientes censurados são aleatorizados, o gráfico pode mudar ligeiramente de uma execução para outra. Por isso, fixamos uma **semente aleatória**.
