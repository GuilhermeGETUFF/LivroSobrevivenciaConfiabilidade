18.1 PACOTES NECESSÁRIOS

Para esta sexta aula prática de Análise de Sobrevivência e Confiabilidade, precisaremos do seguinte pacote:

Código 
require(survival)
  • Pacote survival: É o pacote básico para o estudo de Análise de Sobrevivência e Confiabilidade. Contém as principais rotinas, incluindo definição de objetos Surv, curvas Kaplan-Meier, modelos Cox e modelos paramétricos.

18.2 BASES DE DADOS

18.2.1 CÂNCER DE LARINGE

Neste exemplo, os dados considerados referem-se a um estudo, descrito em Klein e Moeschberger (2003), realizado com 90 pacientes do sexo masculino diagnosticados no período com cancer de laringe. Para cada paciente, foram registrados, no diagnóstico, a idade (em anos) e o estágio da doença (I = tumor primário, II = envolvimento de nódulos, III = metástases e IV = combinações dos 3 estágios anteriores), bem como seus respectivos tempos de morte ou censura (em meses). Os estágios encontram-se ordenados pelo grau de seriedade da doença (menos sério para mais sério). A base de dados está armazenada no objeto laringe.txt.

18.2.2 CÂNCER DE OVÁRIO

Um estudo envolveu o acompanhamento de 26 mulheres após a cirurgia de remoção do tumor. A resposta foi o tempo (em dias), contado a partir do início do tratamento (aleatorização) até a morte do paciente. As seguintes covariáveis foram registradas: Idade e Resíduo (ParcRemovido se o resíduo da doença foi parcialmente removido e Removido se foi completamente removido). Os dados encontram-se no arquivo ovario.txt

18.3 AJUSTE DO MODELO

Para começar a nossa análise dos dados de câncer de laringe, vamos carregar a base de dados:

Código 
dados<-read.table("laringe.txt",header=T)

No R o ajuste do modelo de regressão de Cox será feito a partir da função coxph do pacote survival. A sintaxe da função e sua saída é muito parecida com modelos paramétricos que ja ajustamos:

coxph(formula = Surv(Tempos~Cens)~Covariaveis,
      data = dados)

Como temos duas covariáveis, precisamos fazer uma seleção delas para o modelo final. Assim, vamos ajustar todos os modelos possíveis:

Código 
mod1 <- coxph(Surv(tempos,cens)~idade, data=dados)
mod2 <- coxph(Surv(tempos,cens)~estagio, data=dados)
mod3 <- coxph(Surv(tempos,cens)~idade+estagio, data=dados)
mod4 <- coxph(Surv(tempos,cens)~idade+estagio+idade*estagio, data=dados)

Para escolher qual destes é o melhor modelo, vamos usar como critério, inicialmente, o TRV, comparando os modelos mais simples (mod1, mod2 e mod3) com o modelo mais complexo (mod4). Entretanto, antes da realização do teste, é importante se atentar à quantidade de parâmetros estimados de cada modelo:

  • mod1 = 1 parâmetro
  • mod2 = 3 parâmetros
  • mod3 = 4 parâmetros
  • mod4 = 7 parâmetros

Além disso, a função coxph retorna sempre 2 valores para a função de log-verossimilhança parcial. Veja no seguinte exemplo para o modelo mod1:

Código 
mod1$loglik
[1] -196.8635 -195.5478
  • O primeiro valor é sempre a log verossimilhança parcial do modelo nulo.
  • O segundo valor é a log verossimilhança de fato do modelo ajustado.

Para os nossos TRV, precisaremos utilizar o segundo valor da loglik. Finalmente, podemos fazer os TRV com os seguintes comandos:

Código 
TRV_1 = 2*(mod4$loglik[2]-mod1$loglik[2])
P_valor_1 = pchisq(TRV_1,6,lower.tail=F)
TRV_2 = 2*(mod4$loglik[2]-mod2$loglik[2])
P_valor_2 = pchisq(TRV_2,4,lower.tail=F)
TRV_3 = 2*(mod4$loglik[2]-mod3$loglik[2])
P_valor_3 = pchisq(TRV_3,3,lower.tail=F)

Comparacao <- c("Mod4 x Mod1",  "Mod4 x Mod2",
                "Mod4 x Mod3")
P_valor <- c(
  P_valor_1,  P_valor_2,  P_valor_3
)
TRV<-data.frame(Comparacao,P_valor)
TRV
   Comparacao    P_valor
1 Mod4 x Mod1 0.00119416
2 Mod4 x Mod2 0.08522548
3 Mod4 x Mod3 0.09566532

Ao nível de 5% de significância, os modelos mod2 e mod3 são compatíveis com o modelo mod4. Por serem mais simples, são preferíveis para um melhor ajuste aos dados. Para corroborar a nossa decisão, vamos avaliar os valores de AIC e BIC destes modelos:

Código 
AIC<-c(AIC(mod1),AIC(mod2),AIC(mod3),AIC(mod4))
BIC<-c(BIC(mod1),BIC(mod2),BIC(mod3),BIC(mod4))
AIC_BIC<-cbind(AIC,BIC)
rownames(AIC_BIC)<-c("Idade","Estágio","Idade + Estágio", "Idade + Estágio + Interação")
colnames(AIC_BIC)<-c("AIC","BIC")

As saídas representam:

  • coef: Estimativa dos parâmetros \(\pmb{\beta}\).
  • exp(coef): Exponencial das estimativas dos parâmetros \(\pmb{\beta}\) (útil para interpretação).
  • se(coef): Erro padrão associado às estimativas dos parâmetros \(\pmb{\beta}\).

  • p: P-Valor associado à estatística de teste de Wald.

Observe como não há estimativa para o intercepto. A função de risco de base absorve esse componente. Além disso, a covariável estagio é significativa.

18.4 ADEQUAÇÃO DO AJUSTE

Para verificar a adequação do ajuste, faremos três diagnósticos:

  • Resíduos CoxSnell
  • Teste dos resíduos de Schoenfeld
  • Gráfico dos resíduos de Schoenfeld

18.4.1 RESÍDUOS DE COX-SNELL

Os resíduos de Cox-Snell são utilizados para avaliar a adequação global do ajuste de modelos de sobrevivência. No modelo de Cox, esses resíduos são definidos pela função de risco acumulado estimada para cada indivíduo até seu tempo observado:

\[ r_i = \widehat{H}_i(T_i). \]

No R, os resíduos de Cox-Snell podem ser obtidos diretamente pela função predict(), utilizando o argumento type = "expected", que retorna o risco acumulado estimado para cada indivíduo.

Código 
ResiduoCS <- predict(mod2, type = "expected")

Se o modelo estiver adequadamente ajustado, espera-se que os resíduos de Cox-Snell apresentem comportamento aproximadamente compatível com uma distribuição exponencial de média 1. Portanto, a função de risco acumulado dos resíduos deve se aproximar da reta \(H(r)=r\), enquanto a função de sobrevivência deve se aproximar de \(S(r)=\exp(-r)\).

Os gráficos de diagnóstico são apresentados a seguir:

Código 
par(mfrow = c(1, 2))

ekm <- survfit(
  Surv(ResiduoCS, dados$cens) ~ 1,
  type = "kaplan-meier"
)

# Função de risco acumulado
plot(
  ekm,
  fun = "cumhaz",
  xlab = "Resíduos de Cox-Snell",
  ylab = "Função de risco acumulado"
)
abline(0, 1, col = "red", lwd = 2)

# Função de sobrevivência
plot(
  ekm,
  xlab = "Resíduos de Cox-Snell",
  ylab = "Função de sobrevivência"
)

curve(
  exp(-x),
  from = 0,
  to = max(ResiduoCS),
  col = "red",
  lwd = 2,
  add = TRUE
)
Código 
par(mfrow = c(1, 1))

Conforme observado nos gráficos, as curvas estimadas apresentam comportamento próximo ao esperado teoricamente, indicando uma adequação global satisfatória do modelo de Cox aos dados.

18.4.2 TESTE DOS RESÍDUOS DE SCHOENFELD

Para realizar o teste de hipótese acerca dos resíduos de Schoenfeld, utilizaremos a função cox.zph. Essa função realiza um teste para cada covariável e também faz um teste global.

Para cada covariável as hipóteses são:

\[ H_0:\beta_k(t)=\beta_k \]

\[ H_1:\beta_k(t)\neq\beta_k \]

em que:

  • \(\beta_k(t)\) representa o efeito da covariável ao longo do tempo;
  • \(\beta_k\) representa um efeito constante.

Assim:

  • sob \(H_0\), a covariável satisfaz a hipótese de riscos proporcionais;
  • sob \(H_1\), o efeito da covariável varia ao longo do tempo, violando a hipótese de riscos proporcionais.

Para o teste global as hipóteses são:

\[ H_0:\beta_1(t)=\beta_1,\ \beta_2(t)=\beta_2,\ \ldots,\ \beta_p(t)=\beta_p \]

\[ H_1:\text{Pelo menos uma covariável apresenta efeito dependente do tempo} \]

Assim:

  • sob \(H_0\), todas as covariáveis satisfazem simultaneamente a hipótese de riscos proporcionais;
  • sob \(H_1\), pelo menos uma covariável viola essa hipótese.
Código 
ResiduoSH = cox.zph(mod2)
ResiduoSH
        chisq df    p
estagio  3.59  3 0.31
GLOBAL   3.59  3 0.31

Assim, de acordo com o valor-p a suposição dos riscos proporcionais é satisfeita. Como o modelo possui apenas uma covariável, o teste global é igual ao da covariável.

18.4.3 GRÁFICO DOS RESÍDUOS DE SCHOENFELD

Os seguintes comandos fazem o gráfico dos resíduos de Schoenfeld. Lembre-se que será feito um gráfico para cada covariável. No nosso exemplo, teremos apenas uma representação gráfica:

Código 
plot(ResiduoSH)

Note como não há uma tendência definida no gráfico, corroborando o teste formal.

Para gráficos com mais covariáveis use os comandos par(mfrow=c(.)) para propiciar mais janelas gráficas. Todos os gráficos são feitos de uma vez.

* `z`: **Estatística de teste de Wald**.
* `p`: **P-Valor associado à estatística de teste de Wald**.

Observe como **não há estimativa para o intercepto. A função de risco de base absorve esse componente**. Além disso, a covariável  estagio é significativa.

## **ADEQUAÇÃO DO AJUSTE**

Para verificar a adequação do ajuste, faremos três diagnósticos:

* Resíduos CoxSnell
* Teste dos resíduos de Schoenfeld
* Gráfico dos resíduos de Schoenfeld


### **RESÍDUOS DE COX-SNELL**

Os resíduos de Cox-Snell são utilizados para avaliar a adequação global do ajuste de modelos de sobrevivência. No modelo de Cox, esses resíduos são definidos pela função de risco acumulado estimada para cada indivíduo até seu tempo observado:

$$
r_i = \widehat{H}_i(T_i).
$$

No R, os resíduos de Cox-Snell podem ser obtidos diretamente pela função `predict()`, utilizando o argumento `type = "expected"`, que retorna o risco acumulado estimado para cada indivíduo.

```{r}
ResiduoCS <- predict(mod2, type = "expected")
```

Se o modelo estiver adequadamente ajustado, espera-se que os resíduos de Cox-Snell apresentem comportamento aproximadamente compatível com uma distribuição exponencial de média 1. Portanto, a função de risco acumulado dos resíduos deve se aproximar da reta $H(r)=r$, enquanto a função de sobrevivência deve se aproximar de $S(r)=\exp(-r)$.

Os gráficos de diagnóstico são apresentados a seguir:

```{r}
par(mfrow = c(1, 2))

ekm <- survfit(
  Surv(ResiduoCS, dados$cens) ~ 1,
  type = "kaplan-meier"
)

# Função de risco acumulado
plot(
  ekm,
  fun = "cumhaz",
  xlab = "Resíduos de Cox-Snell",
  ylab = "Função de risco acumulado"
)
abline(0, 1, col = "red", lwd = 2)

# Função de sobrevivência
plot(
  ekm,
  xlab = "Resíduos de Cox-Snell",
  ylab = "Função de sobrevivência"
)

curve(
  exp(-x),
  from = 0,
  to = max(ResiduoCS),
  col = "red",
  lwd = 2,
  add = TRUE
)

par(mfrow = c(1, 1))
```

Conforme observado nos gráficos, as curvas estimadas apresentam comportamento próximo ao esperado teoricamente, indicando uma adequação global satisfatória do modelo de Cox aos dados.


### **TESTE DOS RESÍDUOS DE SCHOENFELD**

Para realizar o teste de hipótese acerca dos resíduos de Schoenfeld, utilizaremos a função `cox.zph`. Essa função realiza um teste para cada covariável e também faz um teste global.

Para cada covariável as hipóteses são:

$$
H_0:\beta_k(t)=\beta_k
$$

$$
H_1:\beta_k(t)\neq\beta_k
$$

em que:

* $\beta_k(t)$ representa o efeito da covariável ao longo do tempo;
* $\beta_k$ representa um efeito constante.

Assim:

* sob $H_0$, a covariável satisfaz a hipótese de riscos proporcionais;
* sob $H_1$, o efeito da covariável varia ao longo do tempo, violando a hipótese de riscos proporcionais.

Para o teste global as hipóteses são:

$$
H_0:\beta_1(t)=\beta_1,\ \beta_2(t)=\beta_2,\ \ldots,\ \beta_p(t)=\beta_p
$$

$$
H_1:\text{Pelo menos uma covariável apresenta efeito dependente do tempo}
$$

Assim:

* sob $H_0$, todas as covariáveis satisfazem simultaneamente a hipótese de riscos proporcionais;
* sob $H_1$, pelo menos uma covariável viola essa hipótese.

```{r}
ResiduoSH = cox.zph(mod2)
ResiduoSH
```

Assim, de acordo com o valor-p a suposição dos riscos proporcionais é satisfeita. Como o modelo possui apenas uma covariável, o teste global é igual ao da covariável.
